The whole internet, in one word: **feral**.

Untamed, unowned, and it bites back. The program writes that word,
and nothing else, to `/output/entry.txt` (5 letters).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
